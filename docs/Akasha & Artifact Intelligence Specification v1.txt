# Genshin Account Progression Planner

# Akasha & Artifact Intelligence Specification v1

## 1. Mục tiêu

Artifact Intelligence phải trả lời ba câu:

```text
1. Artifact build hiện tại của character đã đủ target chưa?

2. Nếu chưa, mức độ thiếu nghiêm trọng đến đâu?

3. Nếu cần farm, domain đó có giá trị cho bao nhiêu character khác trong account?
```

Nó **không trả lời**:

```text
Artifact nào trong kho nên thay?
Món +0 nào nên nâng?
Nên đổi Goblet A sang Goblet B?
Nên strongbox món nào?
Set combination nào cho damage cao nhất?
```

Artifact chỉ là một **progression component** giống Level, Talent và Weapon.

---

# 2. Data Sources

Artifact Intelligence sử dụng hai nguồn khác nhau:

```text
GOOD Snapshot
+
Akasha Evaluation
```

GOOD cho:

```text
artifact đang được equip
set hiện tại
main stat
substat
artifact level
```

Akasha cho:

```text
chất lượng build
RV / roll evaluation
slot quality
các metric đánh giá liên quan
```

Planner **không tự tính quality từ GOOD** trong v1.

---

# 3. Vai trò của GOOD artifact data

GOOD artifact data chủ yếu để:

```text
biết character đang mặc set nào
biết đủ 5 slot hay chưa
biết artifact level
debug discrepancy với Akasha
```

Không dùng để:

```text
tự tính Crit Value
tự đoán build tốt/xấu
tự chọn artifact replacement
```

Akasha là nguồn đánh giá build chính.

# 19. Artifact deficiency

Formula cơ bản:

```python
def artifact_deficiency(current, target):
    if current is None:
        return None

    if current >= target:
        return 0.0

    return (target - current) / target
```

Ví dụ:

```text
Target = .80
Current = .40
Deficiency = .50
```

---

# 20. Non-linear deficiency

Sau tuning có thể dùng curve mạnh hơn:

```python
D = ((target - current) / target) ** gamma
```

Ví dụ:

```text
gamma = 1.2
```

để build cực yếu nổi bật hơn.

Nhưng v1 dùng linear trước.

above:

```text
Artifact .70→.80
```

in most cases.

Nhưng:

```text
Artifact .20→.80
```

của character tier cao có thể vượt:

```text
Talent phụ 8→9
```

Điều này là mong muốn.

# 75. Artifact starvation guard

Ngược lại, không để deterministic upgrades khiến artifact **không bao giờ được farm**.

Vì:

```text
Deficiency + Impact + Tier
```

có thể đủ cao để artifact đi lên.

Không hardcode:

```text
"always do talent before artifact"
```

# 85. Unit tests

| Case                               | Expected                      |
| ---------------------------------- | ----------------------------- |
| Current >= target                  | no ArtifactGoal               |
| Current below target               | generate ArtifactGoal         |
| No Akasha                          | UNKNOWN, no farm task         |
| Artifact gate not met              | goal BLOCKED                  |
| Two chars same domain              | grouped domain task           |
| Character target artifact disabled | ignore Akasha                 |
| Slot metric missing                | overall can still work        |
| OCR unconfirmed                    | planner ignores               |
| Threshold changed                  | reevaluate without new upload |
| Quality reaches target             | goal disappears               |

# 87. Definition of Done

Artifact Intelligence v1 hoàn thành khi:

```text
user có thể nhập Akasha evaluation

evaluation gắn đúng character

raw metrics được lưu

metrics normalize thành quality score

ArtifactTarget được so sánh với current quality

weak slots được identify cho explanation

artifact gate hoạt động

ArtifactGoal cạnh tranh cùng Level/Talent/Weapon

artifact domain resolve từ target set

domain overlap giữa nhiều character được group

artifact goal complete khi quality đạt target

missing Akasha không bị coi là artifact xấu
```
