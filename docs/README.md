# Design specifications

These files preserve domain behavior and data-model requirements created before the native desktop migration.

For current runtime architecture, **`../DESKTOP_ARCHITECTURE.md` is authoritative** whenever an older document mentions a frontend/backend split, HTTP API, browser, localhost or web transport.

Keep using the domain requirements in these specifications (snapshot semantics, planner ordering, inventory allocation, artifact rules, game data), but do not reintroduce a web runtime to satisfy historical transport wording.
