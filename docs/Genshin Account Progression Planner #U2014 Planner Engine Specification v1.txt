# Genshin Account Progression Planner — Planner Engine Specification v1

## 1. Trách nhiệm của Planner Engine

Planner Engine nhận toàn bộ trạng thái account và trả lời:

> Trong tất cả những việc có thể làm cho toàn account, việc nào đáng làm trước, việc nào sau?

Planner phải so sánh được trực tiếp:

```text
Level character A
vs
Ascend character B
vs
Talent character C
vs
Weapon character D
vs
Artifact character E
```

Planner **không tối ưu rotation**, **không quản lý kho artifact**, **không chọn từng artifact để thay**, và **không lập kế hoạch Primogem**.

### Input

```text
AccountState
CharacterTargets
TierConfig
TeamData
MaterialInventory
AkashaEvaluations
GameData
DomainSchedule
UserOverrides
PreviousPlan
```

### Output

```text
PlannerResult
├── GlobalPlan
├── TodayPlan
├── CharacterProgress
├── Explanations
└── UnresolvedProblems
```

# 8. Deficiency Score

`Deficiency` trả lời:

> Character đang cách target bao xa ở component này?

Giá trị:

```text
0.0 → hoàn thành
1.0 → cực kỳ thiếu
```

## Character level

Không dùng đơn giản:

```text
current / 90
```

Thay vào đó dùng milestone ladder:

```text
1
20
40
50
60
70
80
90
```

Ví dụ:

```text
80 → 90
```

chỉ còn một milestone.

Trong khi:

```text
20 → 90
```

còn rất nhiều.

Có thể implement:

```python
def milestone_deficiency(current, target, milestones):
    valid = [x for x in milestones if x <= target]

    current_index = largest_reached_index(current)
    target_index = index(target)

    return (
        target_index - current_index
    ) / max(target_index, 1)
```

# 11. Artifact Deficiency

Artifact không tự suy luận từ GOOD.

Nguồn chính là:

```text
AkashaEvaluation
```

Adapter Akasha phải convert raw data thành:

```python
artifact_quality_score: float
```

trong:

```text
0 → 1
```

Ví dụ sau này có thể map:

```text
VERY_BAD    0.20
BAD         0.40
ACCEPTABLE  0.60
GOOD        0.80
EXCELLENT   1.00
```

Nhưng mapping phải nằm trong config.

Không hardcode trong Planner.

Formula:

```python
D_artifact = max(
    0,
    (target_quality - current_quality)
    / target_quality
)
```

Nếu chưa có Akasha:

```text
artifact state = UNKNOWN
```

không phải:

```text
artifact state = BAD
```

Planner không được tự generate artifact farm dựa trên dữ liệu không tồn tại.


# 16. Base Priority Formula

Planner v1 sử dụng weighted additive scoring.

```text
D = Deficiency
I = Impact
T = Tier Value
U = Team Usage
C = Completion Value
```

Formula mặc định:

```text
BasePriority =
    0.32 × D
  + 0.28 × I
  + 0.18 × T
  + 0.12 × U
  + 0.10 × C
```

Sau đó:

```text
BaseScore = BasePriority × 100
```

Tất cả weight phải nằm trong:

```yaml
planner.yaml
```

Không hardcode.

---

# 17. Tại sao không dùng phép nhân toàn bộ

Không dùng:

```text
D × I × T × U × ...
```

Vì chỉ cần:

```text
team_value thấp
```

là score collapse.

Ví dụ character chưa nằm trong team vẫn phải được build về lâu dài.

Weighted sum ổn định hơn.

# 18. Cost không nằm trực tiếp trong BasePriority

Nếu cho chi phí weight quá lớn:

```text
talent 9 → 10
```

có thể luôn thua các upgrade rẻ dù quan trọng.

Do đó Cost chỉ dùng như **modifier nhẹ**.

```text
Efficiency ∈ 0 → 1
```

Final:

```text
Score =
BaseScore
× EfficiencyModifier
× Confidence
× ManualOverride
```

Trong đó:

```text
EfficiencyModifier =
0.85 + 0.15 × Efficiency
```

Như vậy cost chỉ ảnh hưởng tối đa khoảng 15%.

Nó không phá mục tiêu build account.

# 25. Final Global Score

```python
base = (
    0.32 * deficiency
    + 0.28 * impact
    + 0.18 * tier
    + 0.12 * team
    + 0.10 * completion
)

base_score = base * 100

efficiency_modifier = 0.85 + 0.15 * efficiency

score = (
    base_score
    * efficiency_modifier
    * confidence
    * priority_override
)
```

Sau cùng:

```python
score = clamp(score, 0, 100)
```

Nếu override có thể vượt 100 thì clamp.

# 40. Multi-Step Global Plan

Không chỉ sort current actions một lần.

Planner phải có **iterative simulation**.

Algorithm:

```python
state = clone(account)

plan = []

for i in range(MAX_PLAN_LENGTH):

    goals = generate_goals(state)

    actionable = resolve_dependencies(goals)

    scored = score(actionable)

    best = choose_best(scored)

    plan.append(best)

    simulate_completion(state, best)
```

Sau khi giả lập action #1 hoàn thành:

```text
planner tính lại score
```

rồi mới chọn #2.

Điều này quan trọng.

# 43. Stable Ranking / Anti-Jitter

Nếu:

```text
Action A = 82.4
Action B = 82.1
```

không nên mỗi lần import nhỏ là A/B đổi liên tục.

Dùng hysteresis.

Nếu score difference:

```text
< 3 điểm
```

giữ relative order từ previous plan nếu cả hai vẫn hợp lệ.

Config:

```yaml
ranking:
  reorder_threshold: 3.0
```

Điều này làm app có cảm giác ổn định.

# 53. Anti-Weird Guardrails

Planner bắt buộc tuân theo:

```text
Không recommend talent ngoài target.

Không recommend artifact trước artifact gate.

Không recommend task cần prerequisite chưa hoàn thành.

Không recommend farm material nếu inventory đã đủ.

Không coi unknown inventory = zero.

Không coi missing Akasha = bad artifact.

Không đổi Global Priority vì domain đóng hôm nay.

Không để artifact farming tiếp tục sau target.

Không tạo duplicate tasks cho cùng material/domain.

Không để pin override phá dependency.

Không mark COMPLETE nếu required data đang unknown.

Không sử dụng OCR chưa confirm nếu confidence thấp.
```

# 62. Recommended planner pipeline

```text
1. Validate Context

2. Normalize Account State

3. Load Character Targets

4. Calculate Character Component Progress

5. Generate Upgrade Goals

6. Build Dependency Graph

7. Mark BLOCKED / ACTIONABLE

8. Calculate:
   Deficiency
   Impact
   Tier
   Team
   Completion
   Efficiency

9. Calculate Global Scores

10. Apply Stable Ranking

11. Run Multi-Step Simulation

12. Resolve Material Requirements

13. Compile Tasks

14. Group Shared Domains

15. Check Today Availability

16. Generate Today Plan

17. Generate Structured Reasons

18. Return PlannerResult
```

---

# 63. Pseudocode tổng thể

```python
def run_planner(ctx: PlannerContext) -> PlannerResult:

    account = normalize_account(ctx.account)

    progress = evaluate_character_progress(
        account=account,
        targets=ctx.targets,
        akasha=ctx.akasha,
    )

    goals = generate_upgrade_goals(
        account=account,
        progress=progress,
        targets=ctx.targets,
    )

    dependency_graph = build_dependencies(goals)

    actionable = resolve_actionable_frontier(
        goals,
        dependency_graph,
    )

    for goal in actionable:

        goal.deficiency = calculate_deficiency(goal)

        goal.impact = calculate_impact(
            goal,
            ctx.targets,
        )

        goal.tier_value = resolve_tier(
            goal.character_key,
            ctx.tiers,
        )

        goal.team_value = calculate_team_value(
            goal.character_key,
            ctx.teams,
        )

        goal.completion_value = calculate_completion_bonus(
            goal,
            progress,
        )

        goal.efficiency = estimate_efficiency(
            goal,
            ctx.inventory,
            ctx.game_data,
        )

        goal.global_score = calculate_score(goal)

    global_plan = build_simulated_plan(
        account,
        goals,
        ctx,
    )

    tasks = compile_tasks(
        global_plan,
        inventory=ctx.inventory,
        game_data=ctx.game_data,
    )

    tasks = group_shared_farming(tasks)

    today_plan = filter_today(
        tasks,
        ctx.domain_schedule,
    )

    return PlannerResult(
        global_plan=global_plan,
        today_plan=today_plan,
        progress=progress,
    )
```
