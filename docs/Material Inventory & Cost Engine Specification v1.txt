# 9. Cost resolution

Pseudo:

```python
def resolve_cost(required, inventory):
    result = {}

    for material, amount in required.items():
        owned = inventory.get(material)

        if owned is None:
            missing = None
        else:
            missing = max(0, amount - owned)

        result[material] = {
            "required": amount,
            "owned": owned,
            "missing": missing,
        }

    return result
```

# 14. Do not simulate crafting loss incorrectly

Nếu recipe:

```text
3 lower → 1 higher
```

phải dùng integer division.

Ví dụ:

```text
8 low
```

không tương đương:

```text
2.666 mid
```

Mà:

```text
2 mid
+ 2 low remain
```

Nếu Cost Engine chỉ cần kiểm tra đủ/thiếu thì base-unit model vẫn dùng được trong nhiều trường hợp.

Nhưng nếu cần hiển thị chính xác "cần craft gì", dùng discrete resolver.

# 35. Task compilation

Pseudo:

```python
def compile_goal(goal, resolved_cost):

    if resolved_cost.all_ready:
        return UpgradeNowTask(goal)

    tasks = []

    for missing in resolved_cost.missing_resources:

        source = resolve_source(missing)

        tasks.append(
            build_resource_task(
                goal,
                missing,
                source,
            )
        )

    return tasks
```
