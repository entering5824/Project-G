# Genshin Account Progression Planner

# Database, Snapshot & History Specification v1

## 1. Mục tiêu

Persistence layer phải lưu được:

```text
Account state
GOOD snapshots
Character targets
Tier config
Manual priorities
Material inventory
Akasha evaluations
Planner configuration
History / diffs
```

Nhưng **không được coi Plan là source of truth**.

Nguyên tắc:

```text
SOURCE DATA
    ↓
NORMALIZED STATE
    ↓
PLANNER
    ↓
PLAN
```

Nếu source data thay đổi:

```text
Plan cũ → invalidate
Plan mới → regenerate
```

---

# 2. Những thứ là Source of Truth

Source of truth gồm:

```text
GOOD import
Character Target
Tier Assignment
Manual Priority Override
Material Inventory
Confirmed Akasha Evaluation
Planner Config
Game Data Version
Saved Teams
```

---

# 3. Những thứ KHÔNG phải Source of Truth

Không coi các thứ sau là authoritative:

```text
Current Plan
Today Plan
Priority Score
Character Completion %
Generated Tasks
Calculated Missing Materials
Domain Recommendations
```

Tất cả đều có thể regenerate.

# 19. Import transaction

GOOD import workflow:

```text
validate file
↓
calculate hash
↓
check duplicate
↓
normalize
↓
begin transaction
↓
create snapshot
↓
insert characters/weapons/artifacts/teams
↓
update account.current_snapshot_id
↓
commit
↓
recalculate planner
```

Nếu bất kỳ insert nào fail:

```text
rollback
```

Không được có snapshot nửa vời.


# 103. Nguyên tắc cuối cùng

Database lưu:

> Chuyện gì thực sự đã xảy ra?

Snapshot lưu:

> Account trong game lúc đó trông như thế nào?

Config lưu:

> Cậu muốn Planner đánh giá account theo tiêu chuẩn nào?

Planner Run lưu:

> Với account + config đó, engine đã suy ra điều gì?

History hiển thị:

> Account đã tiến triển ra sao theo thời gian?

Không lớp nào được thay thế vai trò của lớp khác.
